# Screenshots Directory

This folder holds screenshot evidence for each lab in the IT Support Lab portfolio.

## Purpose

Screenshots serve as proof of lab completion and can be referenced in your portfolio, resume, or during interviews.

## Naming Convention

Name each screenshot using the following format:

```
lab<number>-step<number>-<description>.png
```

### Examples

| Filename | Description |
|---|---|
| `lab01-step03-dns-check.png` | DNS resolution test during Active Directory setup |
| `lab02-step01-ipconfig-output.png` | Network adapter configuration output |
| `lab03-step05-sfc-scan.png` | System File Checker scan results |
| `lab04-step02-admin-panel.png` | osTicket admin panel after installation |
| `lab05-step01-script-output.png` | PowerShell script execution output |

## Instructions

1. Take a screenshot at each validation step listed in [evidence-checklist.md](../evidence-checklist.md).
2. Crop the screenshot to show only the relevant window or output.
3. Save as PNG format for clarity.
4. Use the naming convention above so screenshots map directly to the checklist.
5. Add a screenshot for each validation step using the appropriate lab and step number in the filename.

## Tips

- Use **Snipping Tool** or **Win + Shift + S** on Windows to capture specific regions.
- For PowerShell output, consider copying text output to a `.txt` file in addition to a screenshot.
- Ensure no personal or sensitive information is visible in screenshots.
