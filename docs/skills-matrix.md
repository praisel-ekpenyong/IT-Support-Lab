# Skills Matrix

This matrix maps technical skills practiced in each lab to common helpdesk and IT support duties.

| Skill | Lab(s) | Helpdesk Duty | Proficiency Level |
|---|---|---|---|
| Active Directory Management | Lab 01 | Creating and managing user accounts, resetting passwords, maintaining OU structure | Intermediate |
| User Account Management | Lab 01, Lab 05 | Provisioning new users, disabling accounts, managing group memberships | Intermediate |
| GPO Management | Lab 01 | Enforcing security policies, configuring desktop restrictions, deploying software settings | Intermediate |
| DNS Troubleshooting | Lab 01, Lab 02 | Resolving name resolution failures, verifying DNS records, flushing DNS cache | Intermediate |
| Network Diagnostics | Lab 02 | Diagnosing connectivity issues using ping, tracert, ipconfig, and nslookup | Intermediate |
| Windows Troubleshooting | Lab 03 | Identifying and resolving OS-level issues, repairing system files, managing services | Intermediate |
| Event Log Analysis | Lab 03 | Reviewing Event Viewer for errors and warnings, correlating events to reported issues | Beginner |
| Printer Troubleshooting | Lab 03 | Fixing print failures, reinstalling drivers, clearing print queues | Beginner |
| Disk Space Management | Lab 03, Lab 05 | Identifying large files, running Disk Cleanup, monitoring storage usage | Beginner |
| Remote Support | Lab 03 | Assisting end users remotely using built-in tools, guiding users through troubleshooting steps | Beginner |
| Ticketing Systems | Lab 04 | Creating, updating, and resolving tickets; tracking SLAs; documenting resolutions | Intermediate |
| PowerShell Automation | Lab 05 | Automating repetitive tasks such as user creation, log review, and system checks | Beginner |

## How to Use This Matrix

- **Self-Assessment**: Rate your confidence in each skill after completing the associated lab(s).
- **Interview Prep**: Use the Helpdesk Duty column to connect your lab experience to real-world job responsibilities.
- **Resume Building**: Reference the skills and labs when writing resume bullet points (see [resume-bullets.md](resume-bullets.md)).
- **Study Plan**: Focus additional practice on skills rated Beginner to move toward Intermediate proficiency.

## Proficiency Levels

| Level | Description |
|---|---|
| **Beginner** | Completed lab exercises; can perform tasks with reference material |
| **Intermediate** | Comfortable performing tasks independently; can troubleshoot common issues |
| **Advanced** | Can design solutions, mentor others, and handle complex edge cases |
